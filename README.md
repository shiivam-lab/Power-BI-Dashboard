# Power BI Dashboard Portfolio

This repository contains interactive Power BI dashboards created to analyze food delivery and book sales data. The projects focus on KPI tracking, trend analysis, product performance, customer/member analysis, payment methods, delivery status, and sales reporting.

## Projects

### 1. HOP IN - Food Delivery Analytics Dashboard

An interactive Power BI dashboard created to analyze food delivery transactions and customer/member behavior.

#### Key KPIs

- Total Quantity: 15K
- Transactions: 2.75K
- Average Quantity: 5.50

#### Analysis Covered

- Food-wise quantity analysis
- Monthly quantity trends
- Food type and member type analysis
- Delivery status analysis
- Payment method analysis
- Transaction trends by month
- Product/food performance comparison

#### Key Dashboard Metrics

- Delivered: 94.25%
- Cancelled: 5.75%
- UPI Transactions: 1,719
- COD Transactions: 750
- Card Transactions: 277

### 2. Book Sales Analytics Dashboard

An interactive Power BI dashboard created to analyze book sales, transactions, product performance, revenue, and geographic sales distribution.

#### Key KPIs

- Total Transactions: 47
- Net Sales: 43.41K
- Gross Sales: 51.22K

#### Analysis Covered

- Top 5 books sold
- Book revenue comparison
- Day-wise sales analysis
- State-wise net sales
- Gross sales by day
- Transaction/payment status filtering
- Product performance analysis
